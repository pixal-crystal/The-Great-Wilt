
# The Great Wilt

*A pale, silent, calcifying blight spreads from the Iron Roots.*

Walk the canopy, keep the forest in balance, and ricochet through anything that stands in your way.

## About the Game

**The Great Wilt** is a forest adventure featuring exploration, resource gathering, quests, crafting, and momentum-based combat.

Travel across the canopy, interact with the world, and fight enemies while keeping the forest in balance.

## Getting Started

- **Begin a New Season** – Start a new playthrough.
- **Continue** – Resume your current progress.
- **Settings** – Adjust game settings.

## Controls

### Exploration

| Key | Action |
|---|---|
| `W A S D` | Walk |
| `Shift` | Run |
| `E` | Talk / Harvest / Open |
| `Q` | Quests |
| `I` | Crafts & Bag |
| `M` | Pulse Map |
| `O` | Settings |

**Travel:** Walk off a map edge to travel to another area. Traveling takes half a day.

### Combat

| Key | Action |
|---|---|
| Mouse Drag | Pull back to aim |
| Mouse Release | Slingshot yourself toward enemies |
| `Space` | Parry when timed as you hit a wall |
| `Shift` | Dash |
| `1–9` | Use crafted abilities |
| `H` | Use Tonic |
| `B` | Use Bomb |
| Hold `Esc` | Flee combat |

### Combat Mechanics

- **Slingshot:** Drag back and release to launch yourself into enemies.
- **Momentum:** Faster movement results in harder hits.
- **Parry:** Press `Space` right as you hit a wall.
- **Dash:** Use `Shift` to dash.
- **Abilities:** Use keys `1–9` to activate crafted abilities.
- **Escape:** Hold `Esc` to flee an encounter.

## Gameplay Features

- Explore the forest canopy.
- Travel between map areas.
- Harvest resources and interact with the environment.
- Complete quests.
- Craft abilities and manage your inventory.
- Fight enemies using momentum-based combat.
- Navigate using the Pulse Map.
- Keep the forest in balance.
